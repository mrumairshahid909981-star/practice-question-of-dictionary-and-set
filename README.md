# Python Dictionaries and Sets Practice

This repository contains my Python practice programs focused on **Dictionaries** and **Sets**. The purpose of this project is to strengthen my understanding of these important Python data structures through hands-on coding exercises and mini-projects. The repository includes examples of creating, updating, accessing, and deleting dictionary items, working with nested dictionaries, using common dictionary methods, and implementing practical programs such as a Student Marks Manager, Inventory Management System, Phone Book, and Word Frequency Counter. It also demonstrates set operations including adding and removing elements, union, intersection, difference, symmetric difference, subset checking, superset checking, disjoint sets, and removing duplicate values. These programs have helped me improve my Python programming, logical thinking, and problem-solving skills as I continue my journey toward becoming an AI and Machine Learning developer.
